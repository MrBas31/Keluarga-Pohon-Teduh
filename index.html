        FAMILY DATA PROTECTION

        Backup & Recovery

        Lindungi catatan, rencana, dan kenangan keluarga dalam satu tempat.

        Akun terotorisasi
        Data keluarga hanya untuk pengguna yang diizinkan
        Memeriksa status data...

        Buat backup lokal

        Unduh salinan JSON dari data yang sedang terbuka di perangkat ini.

        Pulihkan dari backup

        Pilih JSON untuk memeriksa isi dan kelayakannya sebelum pemulihan.

        Pratinjau backup tervalidasi

        Jaga file backup dengan baik

        File JSON berisi data pribadi keluarga dan saat ini tidak dienkripsi. Jangan mengirimkannya ke grup publik atau menyimpan di perangkat bersama. Saat restore, aplikasi akan lebih dulu mengunduh backup pengaman dari kondisi cloud terkini.

        Google Drive keluarga

        Simpan backup ke folder Drive bersama. Pilih akun Google Drive saat diminta; akun Drive ini terpisah dari login Firebase aplikasi.

        Terbatas
        Google Drive belum dikonfigurasi pada perangkat ini.
        Akun dan kuota: Akun Google Drive terpisah dari akun login Keluarga Pohon Teduh. Jika semua backup ingin memakai kuota Drive utama 400 GB, pilih akun Google utama itu saat diminta pada kedua perangkat. File yang diunggah oleh akun istri ke folder My Drive bersama akan memakai kuota akun istri. Untuk restore, pilih file backup melalui Google Picker agar akses ke file tersebut diberikan secara eksplisit.

        Konfigurasi Google Cloud

        Buka Cloud Console

        Masukkan Client ID, API Key, dan Project Number dari project Google Cloud yang sama. Ketiganya bukan password; tetap batasi API Key ke domain aplikasi dan API yang diperlukan.

        Panduan konfigurasi (perlu dilakukan sekali)
        1. Gunakan satu project Google Cloud khusus untuk Keluarga Pohon Teduh.
        2. Aktifkan Google Drive API dan Google Picker API pada project yang sama.
        3. Di Google Auth Platform, siapkan OAuth consent screen. Pada Data Access, tambahkan scope https://www.googleapis.com/auth/drive.file. Jika status aplikasi masih Testing, tambahkan kedua akun Google pada daftar Test users.
        4. Buat OAuth Client ID bertipe Web application. Pada Authorized JavaScript origins tambahkan https://mrbas31.github.io (tanpa path).
        5. Buat API Key. Batasi Website restrictions ke https://mrbas31.github.io/* dan https://docs.google.com/*. Batasi API ke Google Picker API dan Google Drive API.
        6. Ambil Project Number pada IAM & Admin → Settings. Gunakan nomor angka, bukan Project ID.
        7. Masukkan Client ID, API Key, dan Project Number di atas. Project Number wajib untuk Google Picker. Simpan konfigurasi pada setiap browser/perangkat, lalu pilih folder Drive bersama.

        Jangan pernah memasukkan Client Secret. Aplikasi browser hanya menggunakan Client ID dan API Key yang dibatasi.

        Folder backup bersama

        Belum ada folder yang dipilih untuk akun aplikasi ini.

        Catatan privasi: token Drive hanya disimpan sementara di memori halaman dan tidak dimasukkan ke Firebase atau Local Storage. Aplikasi meminta izin drive.file, bukan akses ke seluruh Drive. Untuk file backup yang dibuat akun pasangan, pilih file tersebut melalui tombol "Ambil backup dari Drive" agar Google memberikan akses ke file itu untuk akun yang sedang dipakai.
