Informasi & perlindungan data

Kebijakan Privasi

Keluarga Pohon Teduh - Baby & Household Planner adalah aplikasi planner keluarga pribadi untuk membantu pengelolaan persiapan kehamilan, persalinan, rumah tangga, serta catatan dan aktivitas keluarga.

Berlaku mulai: 2 November 2026 · Versi kebijakan 1.0

1. Ruang lingkup

Kebijakan ini menjelaskan bagaimana Keluarga Pohon Teduh ("Aplikasi") mengakses, menggunakan, menyimpan, dan melindungi informasi ketika digunakan oleh anggota keluarga yang diberi akses. Aplikasi ditujukan untuk penggunaan keluarga secara pribadi, bukan sebagai layanan publik atau layanan medis.

2. Informasi yang dikelola

Sesuai fitur yang digunakan, informasi yang dimasukkan ke Aplikasi dapat mencakup:

  • Data akun dan identitas autentikasi, seperti identitas pengguna Firebase/Google yang diperlukan untuk masuk dan memeriksa hak akses.
  • Informasi keluarga dan rumah tangga, termasuk anggaran, daftar belanja, dokumen, kalender, dan catatan lainnya.
  • Informasi kehamilan dan persalinan, termasuk tanggal, rencana, pemeriksaan, catatan medis, dan informasi terkait.
  • Informasi bayi/anak yang dimasukkan orang tua atau pengelola, seperti profil, aktivitas harian, pertumbuhan, imunisasi, dan catatan kesehatan.
  • Informasi lain yang secara sukarela dimasukkan pengguna ke dalam Aplikasi.
Perhatian: sebagian informasi tersebut dapat bersifat pribadi atau sensitif, termasuk informasi kesehatan dan data anak. Masukkan hanya informasi yang diperlukan dan jaga akses ke perangkat serta akun yang digunakan.

3. Bagaimana informasi digunakan

Informasi digunakan hanya untuk menyediakan fungsi Aplikasi, seperti menampilkan ringkasan keluarga, mengelola catatan dan daftar, menghitung anggaran, menampilkan grafik, menyinkronkan perubahan antarperangkat anggota keluarga yang berwenang, serta membuat atau memulihkan backup atas permintaan pengguna.

Aplikasi tidak menjual data keluarga, tidak menggunakan data Google untuk iklan, tidak membuat profil iklan, dan tidak menggunakan data Google Drive untuk melatih model kecerdasan buatan.

4. Penyimpanan dan sinkronisasi Firebase

Aplikasi menggunakan Firebase Authentication untuk autentikasi dan Firebase Realtime Database untuk menyimpan serta menyinkronkan data aplikasi. Data aplikasi disimpan pada struktur database keluarga dan akses baca/tulis dibatasi melalui aturan keamanan Firebase kepada akun yang telah diotorisasi oleh pengelola keluarga.

Salinan kerja dan preferensi tertentu juga dapat disimpan di penyimpanan lokal browser (Local Storage), misalnya cache sinkronisasi, preferensi tampilan, konfigurasi publik integrasi Drive, dan identitas folder Drive yang dipilih pada perangkat. Pengguna sebaiknya tidak menggunakan perangkat bersama yang tidak terlindungi.

5. Penggunaan Google Drive

Integrasi Google Drive bersifat opsional. Google Drive hanya diakses setelah pengguna menghubungkan akun Google dan memberikan izin. Aplikasi meminta scope https://www.googleapis.com/auth/drive.file, yang membatasi akses pada file yang dibuat oleh Aplikasi atau file/folder yang dipilih atau diotorisasi pengguna melalui Google Picker. Aplikasi tidak meminta izin untuk menjelajahi seluruh isi Drive.

  • Backup: ketika pengguna memulai backup, Aplikasi mengambil snapshot data keluarga terbaru yang telah tersinkronisasi, lalu mengunggah file JSON ke folder Drive yang dipilih pengguna.
  • Restore: ketika pengguna memilih file backup melalui Google Picker, Aplikasi mengunduh file tersebut untuk divalidasi dan ditampilkan pratinjaunya sebelum pengguna mengonfirmasi pemulihan.
  • Isi backup: file JSON dapat memuat keseluruhan data aplikasi, termasuk catatan keluarga dan informasi kesehatan yang pernah dimasukkan.
  • Token akses: token akses Google Drive digunakan sementara di memori halaman dan tidak disimpan ke Firebase atau Local Storage oleh Aplikasi. Token dibersihkan ketika sesi berakhir, pengguna keluar, atau akun aplikasi berubah.
  • Konfigurasi: Client ID, API Key, nomor project, dan identitas folder yang dipilih disimpan di browser untuk konfigurasi integrasi. Pengguna tetap bertanggung jawab menjaga perangkat dan akun Google yang digunakan.
Pembatasan penggunaan data Google: informasi Google Drive hanya digunakan untuk menjalankan fungsi backup dan restore yang diminta pengguna. Informasi tersebut tidak dijual, tidak digunakan untuk iklan atau profiling, dan tidak dibagikan kepada pihak lain kecuali sejauh diperlukan untuk menyediakan fungsi melalui layanan Google terkait atau sesuai instruksi pengguna (misalnya izin berbagi folder di Google Drive).

6. Berbagi data dan layanan pihak ketiga

Aplikasi menggunakan layanan pihak ketiga berikut untuk menjalankan fungsinya:

  • GitHub Pages untuk meng-host halaman aplikasi dan kebijakan privasi.
  • Google untuk autentikasi yang dipilih pengguna, Google Picker, dan penyimpanan backup di Google Drive apabila integrasi tersebut digunakan.
  • Firebase untuk autentikasi dan database aplikasi.
  • CDN dan penyedia pustaka antarmuka untuk memuat komponen tampilan dan grafik aplikasi.

Aplikasi tidak menjual atau menyewakan informasi keluarga. Izin akses terhadap file backup yang ditempatkan pada folder bersama mengikuti pengaturan berbagi Google Drive yang dibuat oleh pemilik folder dan pengguna.

7. Keamanan dan keterbatasan

Aplikasi menggunakan HTTPS, pembatasan akses melalui Firebase Security Rules, serta scope Google Drive yang dibatasi. Namun, tidak ada sistem yang dapat menjamin keamanan secara mutlak. File backup JSON yang diunduh atau diunggah ke Drive saat ini tidak dienkripsi secara terpisah oleh Aplikasi. Siapa pun yang memperoleh file tersebut atau memiliki izin akses ke folder Drive terkait dapat membaca isinya.

Pengguna bertanggung jawab menggunakan kata sandi dan perangkat yang aman, menjaga daftar akun yang diotorisasi, serta tidak membagikan file backup kepada pihak yang tidak berwenang.

8. Penyimpanan, penghapusan, dan pencabutan akses

Data tetap tersimpan selama diperlukan untuk penggunaan Aplikasi atau sampai dihapus oleh pengelola melalui mekanisme yang tersedia. File backup di Google Drive tetap berada di Drive sampai pengguna yang memiliki izin menghapusnya. Pengguna dapat mencabut izin Google Drive melalui pengaturan keamanan akun Google. Penghapusan cache browser tidak menghapus data Firebase atau file backup di Drive, dan dapat menghilangkan salinan kerja lokal yang belum tersinkronisasi.

9. Privasi anak

Aplikasi dapat menyimpan informasi mengenai bayi atau anak yang dimasukkan oleh orang tua/pengelola keluarga. Aplikasi tidak ditujukan untuk digunakan langsung oleh anak-anak atau untuk mengumpulkan data dari anak tanpa keterlibatan orang tua/wali.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila fitur, layanan, atau cara pengelolaan data berubah. Versi terbaru akan dipublikasikan pada alamat halaman ini beserta tanggal pembaruannya.

11. Kontak

Untuk pertanyaan atau permintaan terkait privasi dan data, hubungi pengelola aplikasi melalui alamat email dukungan yang dicantumkan pada layar persetujuan Google untuk Keluarga Pohon Teduh.
